# Cloud Computing (BTCOC702) - Study Guide & MCQ Portal

Interactive study portal for Cloud Computing (BTCOC702) containing MCQ quizzes with Hinglish explanations and Bloom's Taxonomy categorization, along with descriptive questions and answers.

## Features
- **MCQ Quiz**: Practice multiple-choice questions categorized by Course Outcomes (CO1, CO2, CO3) and Bloom's Levels.
- **Instant Feedback & Explanations**: Detailed explanations including Hinglish breakdowns for every question.
- **Descriptive Section**: Comprehensive descriptive questions with structured answers for mid-sem prep.
- **Responsive Web Portal**: Clean UI styled for desktop and mobile devices.

## Deployment
Deployed as a static web application on [Vercel](https://vercel.com).
The main entry point is `index.html`.
